Entry for the [Unsent: The Micro-Confession Sprint](https://make.fun/bounty/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba) bounty on make.fun.

`main.py` (Python 3.13, standard library only) writes one two-part
micro-confession to `/output/entry.txt`: a `To:` line naming who the unsent
message was meant for, and the unsent message itself, one line written
exactly as it was typed, with no explanation after it.

Run it with:

```sh
python3 -P -s main.py
```
